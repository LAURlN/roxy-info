Privacy Policy

Roxy is a private assistant application used only by its owner. It is not available to other users.

  • Data accessed: With the owner's explicit consent, Roxy accesses the owner's own Google Calendar events and Gmail messages in order to show schedules, create calendar entries, search and read mail, and create or send emails the owner has approved.
  • Storage: Data is processed and stored only on the owner's own computer. OAuth tokens are stored locally with restricted file permissions.
  • Sharing: Google user data is not sold, not shared with third parties, and not used for advertising. It is not used to train generalized AI or machine-learning models.
  • Revocation: Access can be revoked at any time at myaccount.google.com/permissions.

Roxy's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Datenschutzerklärung (Kurzfassung)

Roxy ist ein privater Assistent, den nur sein Besitzer nutzt. Mit dessen Zustimmung greift Roxy auf den eigenen Google Kalender und Gmail zu. Die Daten bleiben auf dem eigenen Rechner, werden nicht verkauft, nicht weitergegeben und nicht für Werbung genutzt. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
